模块由两部分组成：
- `.builds/`：FreeBSD Build Service 的 YAML 任务定义，分别基于 `freebsd/latest` 和 `openbsd/latest` 镜像，安装 go、bash、wireguard 等包，通过 `./wgctrl-go/.cibuild.sh` 完成 WireGuard 内核/用户态准备后执行 `go vet`、`staticcheck`、`go test -race`，并以 `WGCTRL_INTEGRATION=yesreallydoit` 触发集成测试（OpenBSD 使用 `doas`，FreeBSD 使用 `sudo` 启动 `wireguard-go`）。
- `docs/superpowers/plans` 与 `specs`：以 AI 代理可执行的 Markdown 计划与设计规格形式，规划在仓库内新增 `cmd/wg` 及 `internal/wgconfig`、`internal/wgcli` 子包，以现有 `wgctrl.Client` 和各平台后端（Linux netlink、Windows ioctl、userspace socket、FreeBSD nvlist、OpenBSD 只读）为基础，实现与 `wireguard-tools` 当前版本的命令、配置解析、序列化、`syncconf` 差异计算、pretty/dump 输出、终端颜色、密钥生成等行为一致；通过 C oracle 差分测试和专用接口集成测试进行验收。依赖方向为 plans/specs → 目标代码结构（尚未落地），CI 脚本则直接驱动根仓库中已存在的 `wgctrl-go` 源码。
