- 配置型结构体（`Config`、`PeerConfig`）对可选字段使用指针类型，以区分零值与未设置，并在注释中说明 nil 表示不应用该字段。
- 读取型结构体（`Device`、`Peer`）为每个可配置字段配套一个 `HasXxx bool` 标记位，用于指示该字段是否实际来自内核返回。
- 平台差异通过错误类型表达：`Device`/`ConfigureDevice` 在找不到目标时统一返回 `os.ErrNotExist`，调用方可用 `errors.Is` 判断。
- 枚举类型（如 `DeviceType`、`AllowedIPOperation`）配合 `String()` 方法与 `iota` 常量集中声明，便于序列化与调试输出。
