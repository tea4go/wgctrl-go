- 每个子命令实现为 `func(args []string, in io.Reader, out, errOut io.Writer) int` 形式的 `commandFunc`，由 `execute` 统一调度并约定返回码 0 表示成功、非 0 表示错误。
- 对底层 `wgctrl` 客户端的创建通过包级变量（如 `newConfigClient`、`newShowClient`）注入，便于测试时替换为 mock。
- 错误信息统一写入 `errOut` 参数，正常输出写入 `out` 参数，保持 stdout/stderr 分离。
- 对等节点名称通过 `wgmeta.DefaultPath` 读取/更新，并在 show 与 setconf/syncconf 流程中分别以 `attachNames`/`configureWithNames` 形式附加或持久化。
- 未实现的子命令统一映射到 `unimplementedCommand`，返回退出码 1，避免散落的 panic 或未定义行为。
