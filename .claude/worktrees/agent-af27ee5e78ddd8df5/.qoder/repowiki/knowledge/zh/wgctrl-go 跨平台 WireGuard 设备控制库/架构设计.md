根模块以 `golang.zx2c4.com/wireguard/wgctrl` 为单一 Go module 入口，将功能按职责拆分为四个子模块：`public_api` 定义跨平台共享的 Device/Peer/Key/Config 类型及统一 Client 接口；`os_dispatch` 借助 Go 构建标签在编译期选择 Linux netlink、FreeBSD/OpenBSD ioctl、Windows ioctl 等后端，组合出可用的 wginternal.Client 列表；`cmd_tools` 基于该 Client 实现 `wg` 与 `wgctrl` 两个可执行程序；`ci_and_docs` 提供 FreeBSD/OpenBSD CI 脚本与 wg CLI 兼容设计文档。各子模块通过共享的 public_api 类型与 wginternal.Client 契约通信，os_dispatch 作为装配层屏蔽平台差异，cmd_tools 仅依赖上层抽象而不感知具体后端。
