模块由两层组成：顶层 `wgctrl` 包（`client.go`、`doc.go`）暴露统一的 `Client` 结构体，内部维护一个 `[]wginternal.Client` 实现列表，通过遍历调用底层平台特定的 `Devices`/`Device`/`ConfigureDevice` 方法，并以 `os.ErrNotExist` 语义区分“不存在”与“非 WireGuard 设备”；`wgtypes` 子包仅承载纯数据模型（`DeviceType`、`Device`、`Peer`、`Key`、`Config`、`PeerConfig`、`AllowedIPConfig` 等），并通过 `crypto/rand` 与 `golang.org/x/crypto/curve25519` 提供密钥生成与公钥派生能力，不依赖任何平台实现。依赖方向单向：`wgctrl` → `wginternal` + `wgtypes`，`wgtypes` 无外部业务依赖，保证可被多平台实现复用。
